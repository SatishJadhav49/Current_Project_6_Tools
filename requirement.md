```This is common & user based portal for the users where user can create their own reports based on their own excel, csv or manually entry data. 
```Users data should be save in the system where they can access it later for their own reports. The portal should have the following features:
1. User can choose to upload their data in excel or csv format or they can manually enter the data in the portal.
2. User can create their own reports based on the uploaded or manually entered data.
3. User can save their reports in the system for future access.
4. User can view, edit or delete their saved reports.
5. User can share their reports with other users by providing access to specific users.
6. User can export their reports in various formats such as PDF, Excel, or CSV.
7. User can filter and sort their data within the reports for better analysis.
8. User can visualize their data using charts and graphs within the reports.
9. User can create reports within the following graphs & charts:
Fishbone
Box Plot
Pareto Chart
Histogram
Control Chart
Scatter Diagram
Statification
fault tree analysis
10. user can crate multiple data reports for the different usecase for the different names, User will give name.
11. From the single dataset he can crate different types of graphs/reports.
